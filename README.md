# Analytics

Εφαρμογή διερευνητικής ανάλυσης επιχειρηματικών δεδομένων για προϊόντα και πωλήσεις. Ο χρήστης ανεβάζει αρχείο CSV ή Excel, αντιστοιχίζει τις στήλες του και λαμβάνει βασικούς δείκτες, γραφήματα, ενδεικτικά ευρήματα και αναφορά PDF.

> Ακαδημαϊκό πρωτότυπο για πτυχιακή εργασία με θέμα «Ανάλυση Επιχειρηματικών Δεδομένων και Υποστήριξη Αποφάσεων».

## Δυνατότητες

- Ανάγνωση αρχείων CSV, XLSX και XLS.
- Προεπισκόπηση δεδομένων και χειροκίνητη αντιστοίχιση στηλών.
- Σύνοψη εγγραφών, προϊόντων, πωλήσεων και ποσοτήτων, ανάλογα με τα διαθέσιμα πεδία.
- Ραβδογράφημα επίδοσης προϊόντων, γράφημα μεριδίων και, όπου υπάρχουν ημερομηνίες, μηνιαία τάση πωλήσεων.
- Κανόνες για την ανάδειξη προϊόντων με υψηλή ή χαμηλή επίδοση και της χρονικής περιόδου των δεδομένων.
- Εξαγωγή αναφοράς PDF με στατιστικά, προτάσεις και γραφήματα.

## Απαιτήσεις

- Python 3.10 ή νεότερη
- Git για Windows
- Windows 10 ή Windows 11

## Εγκατάσταση και εκτέλεση

Οι παρακάτω οδηγίες είναι για **Windows και Command Prompt (CMD)**.

### Πρώτη εγκατάσταση

1. Εγκατάστησε Python 3.10 ή νεότερη έκδοση και Git για Windows.
2. Άνοιξε το Command Prompt.
3. Εκτέλεσε τις παρακάτω εντολές **μία-μία** για να κατεβάσεις το έργο και να μπεις στον φάκελό του:

```cmd
git clone https://github.com/Lefteris4Paschalidis/Analytics.git
cd Analytics
```

4. Δημιούργησε και ενεργοποίησε εικονικό περιβάλλον:

```cmd
py -m venv .venv
.venv\Scripts\activate.bat
```

5. Εγκατάστησε τις εξαρτήσεις και ξεκίνησε την εφαρμογή:

```cmd
pip install -r requirements.txt
streamlit run app.py
```

Το Streamlit θα εμφανίσει τη διεύθυνση της εφαρμογής. Άνοιξέ τη στον browser· συνήθως είναι <http://localhost:8501>.

### Κάθε επόμενη εκκίνηση

1. Άνοιξε το Command Prompt μέσα στον φάκελο `Analytics` που κατέβασες την πρώτη φορά. Από την Εξερεύνηση αρχείων, άνοιξε τον φάκελο, κάνε κλικ στη γραμμή διεύθυνσης, γράψε `cmd` και πάτησε Enter.
2. Εκτέλεσε τις παρακάτω εντολές μία-μία:

```cmd
.venv\Scripts\activate.bat
streamlit run app.py
```

Δεν χρειάζεται να επαναλάβεις την εγκατάσταση Python ή την εντολή `pip install -r requirements.txt`, εκτός αν αλλάξουν οι εξαρτήσεις του έργου.

## Δεδομένα εισόδου

Το έργο περιλαμβάνει ένα ενδεικτικό CSV για να δοκιμάσεις την εφαρμογή:

- Αρχείο: [`sample_data/superstore_sales.csv`](sample_data/superstore_sales.csv)
- Πηγή dataset: [Superstore Dataset στο Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- Το αρχείο περιέχει 9.994 εγγραφές και πεδία για ημερομηνία παραγγελίας, προϊόν, κατηγορία, πωλήσεις, ποσότητα, έκπτωση και κέρδος.

Για να το δοκιμάσεις, εκκίνησε την εφαρμογή και ανέβασε το `sample_data/superstore_sales.csv` στο πεδίο μεταφόρτωσης. Στην αντιστοίχιση στηλών επίλεξε **Product Name** για προϊόν, **Sales** για πωλήσεις/έσοδα, **Quantity** για ποσότητα και **Order Date** για ημερομηνία. Μπορείς επίσης να επιλέξεις **Category** ή **Sub-Category** για να συγκρίνεις ομάδες προϊόντων.

Μπορείς να ανεβάσεις και δικό σου αρχείο CSV ή Excel. Αν dataset από το Kaggle κατέβει ως ZIP, αποσυμπίεσέ το πρώτα.

Ενδεικτικά πεδία:

| Πεδίο | Χρήση |
| --- | --- |
| Προϊόν / Product | Ομαδοποίηση και σύγκριση προϊόντων |
| Πωλήσεις / Sales ή Revenue | Σύνολα εσόδων και γραφήματα |
| Ποσότητα / Quantity | Σύνολα τεμαχίων |
| Ημερομηνία / Date | Μηνιαία τάση πωλήσεων |

Οι ονομασίες στηλών δεν είναι υποχρεωτικές, καθώς ο χρήστης τις επιλέγει μέσα στην εφαρμογή. Για αναλύσεις πωλήσεων, η σχετική στήλη πρέπει να περιέχει αριθμητικές τιμές.

## Μεθοδολογία και όρια

Οι προτάσεις παράγονται με απλούς, διαφανείς κανόνες κατάταξης και συγκέντρωσης των δεδομένων. Η εφαρμογή δεν υπολογίζει κέρδος ή περιθώριο κέρδους εκτός αν υπάρχουν τα απαραίτητα δεδομένα και δεν αποτελεί σύστημα πρόβλεψης. Τα ευρήματα είναι ενδείξεις για περαιτέρω διερεύνηση και η τελική απόφαση ανήκει στον χρήστη.

## Ιδιωτικότητα

Η εφαρμογή δεν περιλαμβάνει κώδικα αποθήκευσης ή αποστολής των ανεβασμένων αρχείων σε εξωτερική υπηρεσία. Σε δημόσια εγκατάσταση, η διαχείριση αρχείων εξαρτάται και από την πλατφόρμα φιλοξενίας. Μην ανεβάζεις ευαίσθητα ή προσωπικά δεδομένα σε δημόσια υπηρεσία χωρίς την κατάλληλη άδεια.
